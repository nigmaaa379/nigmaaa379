### 🎯 Current Ventures

#### 🏢 **FinMind** (Haven) — *Autonomous AI for Remote Professionals*
> **Mission:** Protecting your money & mental health from financial pressure and burnout.<br>
> **Killer Feature:** One-click "Autonomous Safety Mode" — AI negotiates bills, blocks intrusive meetings, monitors stress patterns.<br>
> **Model:** B2C Subscription ($9.99/week) + B2B2C (HR Departments via EAP programs)<br>
> **Moat:** Cross-domain dataset linking financial transactions + behavioral stress markers + calendar data.<br>
> **Stack:** Python, LangChain, React, PostgreSQL, AWS Lambda, Behavioral Analytics<br>
> [📄 Executive Summary](#) | [🌐 Landing Page](#) | [💬 Contact for Demo]

#### ⛓️ **CodeChain** — *Guild Warfare Meets Competitive Coding*
> **Mission:** Transforming competitive programming into epic team-based battles with crypto rewards.<br>
> **Features:** Guild Wars System, AI-powered problem recommendations, Anti-cheating telemetry, Community bounties.<br>
> **Traction:** Full-stack platform with React + FastAPI + Solidity smart contracts.<br>
> **Stack:** React 18, TypeScript, FastAPI, Python 3.11, PostgreSQL, Solidity, Docker, Prometheus<br>
> [🔗 GitHub Repo](https://github.com/niswa123/CodeChain) | [📖 Documentation](https://github.com/niswa123/CodeChain/blob/main/docs/QUICK_START.md) | [🎮 Live Demo](#)

#### 🧾 **GrantAI** — *Automated R&D Tax Credits with AI Precision*
> **Mission:** Convert engineering efforts into audit-proof tax credits using LLM-powered analysis.<br>
> **Magic:** Two-pass LLM engine classifies R&D-eligible work from GitHub/Jira/Linear, generates compliant claims in minutes.<br>
> **Security:** Enterprise-grade with rate limiting, Turnstile CAPTCHA, HMAC webhook validation, tier-based access control.<br>
> **Stack:** Next.js 15, React 19, Tailwind CSS v4, Prisma, PostgreSQL, Stripe, NOWPayments, Inngest<br>
> [🔗 GitHub Repo](https://github.com/niswa123/GrantAI) | [✨ Features Overview](#) | [🔒 Security Posture](#)

#### 📊 **AIOps Platform** — *Observability & Governance for AI Agents*
> **Mission:** Cost tracking, distributed tracing, and governance for AI Agents and MCP servers.<br>
> **Capabilities:** Real-time monitoring, ClickHouse analytics, Kafka streaming, multi-agent orchestration.<br>
> **Stack:** FastAPI, Python, ClickHouse, PostgreSQL, Redis, Redpanda, Next.js, Kubernetes<br>
> [🔗 GitHub Repo](https://github.com/niswa123/AIOps-Platform) | [📈 Tech Stack](#)

### 🧠 The Philosophy: Why These Products?

All my ventures solve the same core problem: **Technology should serve humans, not exhaust them.**

- **FinMind** fights financial pressure + burnout synergy for remote workers
- **CodeChain** makes skill-building engaging through gamification & community
- **GrantAI** removes bureaucratic hell from R&D tax claims
- **AIOps** brings observability to the chaotic world of AI agents

> *"People don't need another AI tool. They need AI that works **for** them, autonomously, with human oversight."*
